# Instructions for the Scout — Job Search HQ

Salman will send you a link to a Google Sheet called **Job Search HQ**.
Bookmark it. You will use it every day.

You only work in one tab: **"Scout — Jobs"** (tabs are at the bottom of the screen).
A robot reads this tab every 2 hours. It helps you — you do not need to do anything for it.

## Every day

1. Open the sheet. Click the tab **"Scout — Jobs"**.
2. Search for jobs that match Salman's preferences.
   The preferences are in the tab **"Scout — Preferences"** (job titles, industries, address).
3. For every job you find, add **one new row** at the bottom. Fill these columns:
   - **Company** — the company name
   - **Position** — the job title
   - **Job Link** — the web address of the job page. This is the most important column.
   - **City** and **State**
   - **Salary Range** — if the job shows it
   - **Min Experience** — years of experience the job asks for, if it shows it
   - **Date Searched** — today's date
4. If you do not know something, leave that column empty. That is OK.
5. **Before you apply**, look at the warning columns on the right side of the row:
   - **· duplicate** — if it says "⚠ already in Pipeline", Salman already has this job. Skip it.
   - **· do_not_apply** — if it shows a ⚠ warning, do not apply to this company. Skip it.
   - The robot writes these warnings within 2 hours. Good plan: add your jobs first,
     do other work, then come back and apply to the rows with no warning.
6. When you apply to a job, **tick the "Applied" checkbox** in that row.
7. Apply to **10 to 12 jobs per day**.

## Rules for applying

1. Apply **on the company's own website only**. This is called applying "direct".
2. **Never** apply through LinkedIn, Indeed, or staffing companies.
3. Use this email to create accounts on job sites: **salmanshaheen.t@gmail.com**
   Salman will send you the password in a private message.
   **Never write the password in the sheet.**
4. Always use the newest resume. The link is in the **"Scout — Preferences"** tab,
   in the row **"Your resume (always current)"**. Download it fresh each day —
   the file there is always up to date.

## Things that break the robot (please do not do these)

1. **Do not paste the same Job Link in two rows.** One job = one row.
   If you do this by mistake, delete the extra row.
2. **Do not type in the columns that start with "· "** (like "· duplicate").
   The robot writes those. If you type there, the robot will overwrite it.
3. **Do not sort the sheet** with Data → Sort. If you want to sort or filter,
   use **Data → Filter views → Create new filter view**. A filter view only
   changes what YOU see. It does not move the rows for anyone else.
4. **Do not delete rows.** Old rows stay in the sheet.

## If something looks wrong

- If the column **· validation** says "missing: ..." — that row is missing information.
  Please fill in the missing columns.
- If you have any question, ask Salman. Do not guess.
