## Atomic packets

### PKT-03A Dictionary and anti-slop

Integrate the completed display dictionary and CI checks. User strings cannot expose
engine vocabulary. Computed styles reject gradients, uppercase transforms, letter
spacing, italics, radius over 12px, opacity-only de-emphasis, non-tabular numeric
columns, and interpunct glue. Each rule has a failing violation fixture.

### PKT-03B App shell

Five destinations plus Settings; 224px rail at desktop; Today-only badge; exact active,
focus, responsive, pending, suspended, and mobile navigation states. No dead routes.

### PKT-03C Shared components

Port the supplied components and preserve existing command semantics. Each receives
production and fixture interfaces, semantic roles, keyboard behavior, and all design
states.

### PKT-03D Command palette and system routes

Build command palette, add-job flow, shortcuts overlay, 404, 500, maintenance, session
expiry, and safe no-results behavior.

### PKT-03E Offline and conflict

When truly offline, disable writes and show approved explanation. Do not queue mutations
in local storage. Preserve unsaved form input locally only when it contains no unsafe
credential/content. Conflicts preserve drafts and offer reload/compare.

### PKT-03F Parity harness

Version a route/state/viewport manifest, design digest, fixture scenario, semantic
oracle, geometry evidence, computed-style results, and screenshot. Include 320/375/768/
1024/1440, large type, zoom, long strings, keyboard, focus, reduced motion, and contrast.

## Escalate

Any visual or interaction state absent from the design, any design/accessibility
conflict, or any request to alter the owner design source.
